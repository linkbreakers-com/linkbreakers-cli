## linkbreakers page-themes apply-page-theme-template

Apply a page theme template to a link

### Synopsis

Copies a template's styling into the link's own page theme. The link keeps its
own theme row, so the template can later be edited or deleted without changing
any page that was styled from it. Cover, badge and footer logo media are copied into the
caller's workspace when the template carries them.

Requires the `page_themes:write` scope.

API: POST /v1/page-themes/apply-template

```
linkbreakers page-themes apply-page-theme-template [flags]
```
