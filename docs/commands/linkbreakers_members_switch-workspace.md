## linkbreakers members switch-workspace

Switch workspace

### Synopsis

Issue an access token for another workspace the signed-in person belongs to. Needs a dashboard session or a full-access token of a member; a workspace token or a token limited to scopes is refused. When the workspace enforces MFA, the first call emails a code and answers MFA_REQUIRED; repeat it with mfa_code.

Requires the `members:write` scope.

API: POST /v1/myself/workspaces/{workspaceId}:switch

```
linkbreakers members switch-workspace [flags]
```
