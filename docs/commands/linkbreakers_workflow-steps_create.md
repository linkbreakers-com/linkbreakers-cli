## linkbreakers workflow-steps create

Create a new workflow step

### Synopsis

This endpoint allows users to create a new workflow step for a link.
Workflow steps define the behavior of links, such as redirection destinations.

Requires the `workflows:write` scope.

API: POST /v1/links/{linkId}/workflow-steps

```
linkbreakers workflow-steps create [flags]
```
