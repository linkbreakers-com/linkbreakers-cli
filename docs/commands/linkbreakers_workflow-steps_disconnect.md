## linkbreakers workflow-steps disconnect

Clear one exit of a workflow step

### Synopsis

Leaves the branch with no destination. Clearing a branch that is already
clear succeeds. See Connect for what a branch id is.

Requires the `workflows:write` scope.

API: DELETE /v1/links/{linkId}/workflow-steps/{stepId}/branches/{branchId}/connection

```
linkbreakers workflow-steps disconnect [flags]
```
