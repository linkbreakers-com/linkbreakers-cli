## linkbreakers media list

List media files

### Synopsis

Retrieves the workspace's ready media files, newest first, optionally narrowed to one kind or
to where they were uploaded from. total_count is every item matching the filters across all
pages. Each item lists its references: where it is used.

Requires the `media:read` scope.

API: GET /v1/media

```
linkbreakers media list [flags]
```

### Options

```
      --cursor string          Opaque cursor from the previous page's nextPageToken. Same as pageToken; when both are sent, pageToken wins.
  -h, --help                   help for list
      --kind string            Only media of this kind. Unset lists every kind.
      --page-size int          The maximum number of media files to return. Required.
      --page-token string      The token for retrieving the next page of results If not provided, the first page of results will be returned
      --uploaded-from string   Only media uploaded from this place. Unset lists media from everywhere. Where media was uploaded from says nothing about where it can be used: read references for that.
      --usage string           Deprecated: filter by uploaded_from instead. Still matches the value recorded at upload, which says nothing about where the media is used.
```
