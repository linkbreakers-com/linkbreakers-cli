## linkbreakers workflow-steps export

Export workflow steps

### Synopsis

Writes the steps you name, with all their settings and the connections
between them, as a self-contained JSON document that names steps by local
keys rather than ids. Import it into any link's workflow to copy the
steps; it is the same document the dashboard puts on the clipboard when
steps are copied on the canvas.

Name the link's entry (the visit step) with the others to record what it
leads to: imported into another link, that link's own entry then leads to
the copy. The entry itself is never in the document.

Requires the `workflows:read` scope.

API: POST /v1/links/{linkId}/workflow-steps/export

```
linkbreakers workflow-steps export [flags]
```
