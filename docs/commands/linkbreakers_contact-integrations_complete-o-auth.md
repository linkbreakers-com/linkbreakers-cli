## linkbreakers contact-integrations complete-o-auth

Finish signing in to a contact tool

### Synopsis

Exchange the code the sign-in returned (with the PKCE verifier kept for its state), check the account, and connect the tool like ConnectTool. The state is valid once, for 15 minutes, for the member who started the sign-in.

Requires the `integrations:write` scope.

API: POST /v1/integrations/contacts/{tool}/oauth/complete

```
linkbreakers contact-integrations complete-o-auth [flags]
```
