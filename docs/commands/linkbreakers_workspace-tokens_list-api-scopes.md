## linkbreakers workspace-tokens list-api-scopes

List the scopes a token can have

### Synopsis

A scope is one permission, such as `links:read` or `links:write`: it names a resource and what the token may do with it. Every authenticated endpoint requires exactly one scope, named on the endpoint, and a write scope also grants the read scope of the same resource.

You pick a token's scopes when you [create it](https://linkbreakers.com/help/api/workspace-tokens#create-a-workspace-token); a token created without any has full access. This lists every scope with the resource it covers and what it allows. Needs no authentication.

API: GET /v1/workspace-tokens/scopes
