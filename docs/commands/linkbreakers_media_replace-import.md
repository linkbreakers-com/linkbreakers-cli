## linkbreakers media replace-import

Replace a media file from a URL

### Synopsis

Replaces the file of an existing media item with one fetched server-side, from a public https url or
a file the caller attached to their own Assistant conversation, in one call. The same checks as
CompleteReplace apply, with the same limits and URL rules as Import: every use rendered from the
media must accept the new file (MEDIA_REPLACE_NOT_ALLOWED lists each refusing use and why), a file
another media item holds is refused with MEDIA_ALREADY_EXISTS, and only the size difference counts
against the storage allowance. The media keeps its id; QR code designs using it as a logo keep their
current logo and are detached from it. A file identical to the media's own returns unchanged true.

Requires the `media:write` scope.

API: POST /v1/media/{id}/replace:import

```
linkbreakers media replace-import [flags]
```
