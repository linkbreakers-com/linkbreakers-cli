## linkbreakers page-themes update-page-theme

Update a page theme

### Synopsis

Updates an existing page theme. Cannot update page themes that are currently attached to links.

Requires the `page_themes:write` scope.

API: PATCH /v1/page-themes/{id}

```
linkbreakers page-themes update-page-theme [flags]
```
