## linkbreakers workspace-tokens update

Update a workspace token

### Synopsis

Rename a workspace token or change its scopes. Changes reach every request within 30 seconds. A token can only grant scopes it holds itself.

Requires the `tokens:write` scope.

API: PATCH /v1/workspace-tokens/{id}

```
linkbreakers workspace-tokens update [flags]
```
