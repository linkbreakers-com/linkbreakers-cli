## linkbreakers signup

Create a Linkbreakers workspace and save its API token, in one step

### Synopsis

Creates a free Linkbreakers workspace and saves an API token for it, so every other command works right away.

The workspace is handed to the person whose email you pass: they receive a link and a 6-digit code to claim it. Until they do, the token can create and manage links, QR codes, workflows and page themes and read analytics. An unclaimed workspace is deleted with everything in it 24 hours after signup.

Already have an account? Create a token in the dashboard and run `linkbreakers auth set-token` instead.

```
linkbreakers signup [flags]
```

### Examples

```
  linkbreakers signup --email you@example.com
  linkbreakers links create --destination https://example.com --name "My first link"

```
