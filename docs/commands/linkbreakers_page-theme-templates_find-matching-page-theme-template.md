## linkbreakers page-theme-templates find-matching-page-theme-template

Find a page theme template matching a link's styling

### Synopsis

Returns the page theme template available to the workspace whose styling is identical to the link's current page theme, if one exists. Saving the theme as a template again would only duplicate it.

Requires the `page_themes:read` scope.

API: GET /v1/page-themes/matching-template

```
linkbreakers page-theme-templates find-matching-page-theme-template [flags]
```
