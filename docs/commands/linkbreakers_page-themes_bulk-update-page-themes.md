## linkbreakers page-themes bulk-update-page-themes

Restyle many links' page themes

### Synopsis

Applies a template, values or both to the page theme of up to 50 links named
by id or short link. A later entry replaces an earlier one for the links it
names. Each link succeeds or fails on its own: read the result of each one.

Requires the `page_themes:write` scope.

API: POST /v1/page-themes/bulk-update

```
linkbreakers page-themes bulk-update-page-themes [flags]
```
