## linkbreakers media complete-upload

Complete a direct media upload

### Synopsis

Checks the file PUT to the upload_url: its size, its real format read from its first bytes,
and the storage allowance. When it matches what CreateUpload declared, the media becomes READY
and is returned with a signed URL. When it does not, the file and the media are discarded and
the error says why; start a new upload. Completing a media item that is already READY returns it.

The server always establishes the file's SHA-256 itself, from the checksum storage verified or by
reading the file back. A file the workspace already holds is discarded with 409
MEDIA_ALREADY_EXISTS; the error's metadata names the existing media in existingMediaId and
existingFileName. Use that media instead.

Requires the `media:write` scope.

API: POST /v1/media/{id}:complete

```
linkbreakers media complete-upload [flags]
```
