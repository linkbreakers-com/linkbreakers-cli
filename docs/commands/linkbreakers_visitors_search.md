## linkbreakers visitors search

Search visitors

### Synopsis

Same as List visitors, with the parameters sent as a JSON body so they can include attributeFilters. Every filter must match, for example budget at least 800000 and timeline equal to under_6_months.

Requires the `visitors:read` scope.

API: POST /v1/visitors/search

```
linkbreakers visitors search [flags]
```
