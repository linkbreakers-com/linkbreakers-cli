## linkbreakers form-integrations connect

Connect a form tool with an API key

### Synopsis

Connect Tally, Jotform or Paperform with the account's API key. The forms behind the workspace's links are prepared at once: a hidden lbid field and a webhook.

Requires the `integrations:write` scope.

API: POST /v1/form-integrations/{tool}/connect

```
linkbreakers form-integrations connect [flags]
```

### Options

```
      --api-key string           The account's API key: Tally Settings > API keys, Jotform Settings > API, Paperform Account > Developer.
      --data string              Request body as JSON. Use @file.json to read a file or - for stdin. Flags set fields on top of it.
  -h, --help                     help for connect
      --idempotency-key string   Makes retrying this request safe. See components.parameters.IdempotencyKey.
      --region string            Jotform only: EU or HIPAA when the account lives there.
      --tool string              Required.
```
