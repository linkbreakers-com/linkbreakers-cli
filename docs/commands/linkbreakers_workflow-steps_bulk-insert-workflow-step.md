## linkbreakers workflow-steps bulk-insert-workflow-step

Insert one step into many links' workflows

### Synopsis

Inserts the same step, usually a condition, into the workflow of up to 50
links, named by id or short link. Each link succeeds or fails on its own:
read the result of each one. Calling again for a link that succeeded inserts
a second step. A link with BULK_EDIT_NOT_STARTED was left untouched because the
call ran out of time: send those again in a new call.

Requires the `workflows:write` scope.

API: POST /v1/workflow-steps/bulk-insert

```
linkbreakers workflow-steps bulk-insert-workflow-step [flags]
```
