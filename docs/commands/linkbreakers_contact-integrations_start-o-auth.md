## linkbreakers contact-integrations start-o-auth

Start signing in to a contact tool

### Synopsis

Return the URL where the person signs in to a contact tool that connects with OAuth (Salesforce, Zoho CRM). The sign-in comes back to the app's redirect URL with a code and a state, which CompleteOAuth exchanges.

Requires the `integrations:write` scope.

API: POST /v1/integrations/contacts/{tool}/oauth/start

```
linkbreakers contact-integrations start-o-auth [flags]
```
