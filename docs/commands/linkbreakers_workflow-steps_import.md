## linkbreakers workflow-steps import

Import workflow steps

### Synopsis

Creates the steps of a document made by Export, or copied from the
dashboard's canvas, in the workflow of the link in the path. The steps get
new ids and the connections the document lists between them.

The entry is never duplicated. When the document says what the entry led
to, this link's own entry is connected to that step's copy; what it led to
before stays in the workflow, unconnected. Imported into the link it was
exported from, that part is ignored.

Everything is checked as if each step were created on its own. A step
handing out media, or a chat bot talking through an agent, that this
workspace does not have is left out, with a notice. All the steps are
created, or none.

Requires the `workflows:write` scope.

API: POST /v1/links/{linkId}/workflow-steps/import

```
linkbreakers workflow-steps import [flags]
```
