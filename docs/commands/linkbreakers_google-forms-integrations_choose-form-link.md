## linkbreakers google-forms-integrations choose-form-link

Choose a Google Form's link

### Synopsis

When the same Google Form is behind several links, timing cannot tell which link a response came from. This records the link its responses belong to.

Requires the `integrations:write` scope.

API: POST /v1/google-forms-integrations/forms/{formId}/link

```
linkbreakers google-forms-integrations choose-form-link [flags]
```
