## linkbreakers sandboxes create

Create a sandbox

### Synopsis

Create an API-only sandbox workspace and return its first token. The token starts with `lb_test_`, holds the scopes of the credential that created it, and is shown only once. Call this with a live workspace credential; a sandbox cannot create sandboxes.

Requires the `tokens:write` scope.

API: POST /v1/sandboxes

```
linkbreakers sandboxes create [flags]
```
