## linkbreakers google-analytics-integrations update

Connect Google Analytics

### Synopsis

Connect a Google Analytics 4 property, or change its settings. Every person's visit, form submission and piece of visitor data captured is then sent to it through the Measurement Protocol, without personal data. With visitor_attributes_enabled on (the default), form answers and custom visitor attributes go with each event as lb_<key> parameters, numbers as numbers; visitor_attribute_keys limits them to chosen keys.

Requires the `integrations:write` scope.

API: PUT /v1/integrations/google-analytics

```
linkbreakers google-analytics-integrations update [flags]
```

      --data string                     Request body as JSON. Use @file.json to read a file or - for stdin. Flags set fields on top of it.
  -h, --help                            help for update
      --idempotency-key string          Makes retrying this request safe. See components.parameters.IdempotencyKey.
      --measurement-id string           GA4 Measurement ID, e.g. "G-ABC123DEF4".
      --visitor-attribute-keys string   Send only these attribute keys. Omit to keep the current list; an empty list sends every attribute that is not personal data. JSON value.
      --visitor-attributes-enabled      Add the visitor's data (form answers such as a rating, custom visitor attributes) to events as parameters, never personal data. Omit to keep the current setting; on by default when connecting.
