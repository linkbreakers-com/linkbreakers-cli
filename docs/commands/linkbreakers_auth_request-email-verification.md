## linkbreakers auth request-email-verification

Request email verification

### Synopsis

Send a verification email to a member of the caller's workspace whose email is not verified yet. Opening the link verifies the address and the workspace, which lifts a WORKSPACE_UNVERIFIED pause. Callable while the workspace is paused. The email must belong to a member of the workspace; one email per address per minute and 5 per day.

Requires the `members:write` scope.

API: POST /v1/auth/email/verification/request

```
linkbreakers auth request-email-verification [flags]
```
