## linkbreakers jobs get

Get a job

### Synopsis

Returns a background job's status: JOB_STATUS_PENDING (accepted, waiting
to run), JOB_STATUS_RUNNING, JOB_STATUS_SUCCEEDED (linksBulkCreate holds
the created link IDs, in the order submitted) or JOB_STATUS_FAILED (error
says why; no link was created). Poll it, every few seconds, until it is
SUCCEEDED or FAILED. Today the only job is a bulk link creation started
with POST /v1/links/bulk/jobs, whose Location header is this URL.

Requires the `links:read` scope.

API: GET /v1/jobs/{id}

```
linkbreakers jobs get [flags]
```
