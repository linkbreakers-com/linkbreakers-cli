## linkbreakers jobs get

Get a job

### Synopsis

Returns a background job and where it stands. Today every job is a bulk
link creation started with `POST /v1/links/bulk/jobs`: its 202 Accepted
response carries this job's URL in the `Location` header.

Read the job every few seconds until it is finished:

- `JOB_STATUS_PENDING`: accepted, waiting to run. Check again.
- `JOB_STATUS_RUNNING`: creating the links. Check again.
- `JOB_STATUS_SUCCEEDED`: done. `linksBulkCreate.linkIds` lists the created
  links, in the order you sent them.
- `JOB_STATUS_FAILED`: `error` says why. No link was created: a batch is
  all or nothing.

A job can be read for 24 hours after it finishes; after that, this
answers `JOB_NOT_FOUND`.

Requires the `links:read` scope.

API: GET /v1/jobs/{id}

```
linkbreakers jobs get [flags]
```
