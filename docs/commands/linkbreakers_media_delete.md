## linkbreakers media delete

Delete a media file

### Synopsis

Removes a media file from the workspace and frees its storage. This operation cannot be undone.
Media still opened by an Open media step, or shown by a page theme as its background cover,
badge or footer logo (of a link or of a page theme template), is refused with MEDIA_IN_USE,
naming what uses it (metadata linkIds and pageThemeTemplateIds): point those at other media or
remove it from them first. Deleting an image a QR code design uses as its logo is allowed: the
QR code keeps its own copy of the logo, and its link to the media is cleared.

Requires the `media:write` scope.

API: DELETE /v1/media/{id}

```
linkbreakers media delete [flags]
```
