## linkbreakers links create-bulk-async

Create links in bulk in the background

### Synopsis

Accepts the same batch as POST /v1/links/bulk, answers 202 Accepted at
once with a job and a Location header, and creates the links in the
background. Poll GET /v1/jobs/{id} for the result. The batch is
transactional: when the job fails, no link was created.

Requires the `links:write` scope.

API: POST /v1/links/bulk/jobs

```
linkbreakers links create-bulk-async [flags]
```
