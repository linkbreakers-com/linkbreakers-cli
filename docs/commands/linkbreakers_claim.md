## linkbreakers claim

Hand the workspace created by `linkbreakers signup` to a person

### Synopsis

Emails the person a link and a 6-digit code to claim the workspace `linkbreakers signup` created, and prints both so you can pass them on too. Each call replaces the previous link. With --wait, it waits until the workspace is claimed and then upgrades the saved token to the claimed workspace's permissions.

```
linkbreakers claim [flags]
```

### Examples

```
  linkbreakers claim --email you@example.com
  linkbreakers claim --wait

```

### Options

```
      --email string   Email of the person to hand the workspace to. Defaults to the one given at signup.
  -h, --help           help for claim
      --wait           Wait until the workspace is claimed, then upgrade the saved token.
```
