## linkbreakers qrcode-designs update

Update a QR code design

### Synopsis

Apply styling tweaks or media changes to an existing QR code design.

Requires the `qrcodes:write` scope.

API: PATCH /v1/qrcode-designs/{id}

```
linkbreakers qrcode-designs update [flags]
```
