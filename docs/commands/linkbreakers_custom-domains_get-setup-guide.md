## linkbreakers custom-domains get-setup-guide

Get the setup guide for a custom domain

### Synopsis

Detects which DNS provider manages the domain from its nameservers and returns
everything needed to connect it: the provider's name and a link to its DNS
settings, the exact records to add (with the host written the way that
provider expects it), provider-specific hints, and a one-click setup URL when
the provider supports Domain Connect for Linkbreakers.

Requires the `domains:read` scope.

API: GET /v1/custom-domains/{id}/setup-guide

```
linkbreakers custom-domains get-setup-guide [flags]
```
