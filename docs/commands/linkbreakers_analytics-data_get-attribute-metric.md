## linkbreakers analytics-data get-attribute-metric

Get visitor attribute metric

### Synopsis

Returns count, average, minimum and maximum for a visitor attribute, plus how much of the audience carries it.

Requires the `analytics:read` scope.

API: POST /v1/analytics/attributes/metric

```
linkbreakers analytics-data get-attribute-metric [flags]
```
