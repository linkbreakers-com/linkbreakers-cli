## linkbreakers retargeting-pixels update

Update retargeting pixels

### Synopsis

Set, change or remove the ad platform pixels fired on link visits, and which links each fires on. Omitted fields keep their value and an empty string removes a pixel. A pixel fires on every link by default; a scope with SELECTED_LINKS limits it to some links, directories (with their sub-directories) and tags, and a pixel left out of scopes keeps its scope. Visits a pixel fires on go through a short browser page that fires the pixels and then redirects, which adds a short delay; visits no pixel fires on redirect instantly.

Requires the `integrations:write` scope.

API: PUT /v1/retargeting-pixels

```
linkbreakers retargeting-pixels update [flags]
```
