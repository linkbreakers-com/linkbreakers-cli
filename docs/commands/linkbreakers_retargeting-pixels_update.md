## linkbreakers retargeting-pixels update

Update retargeting pixels

### Synopsis

Set, change or remove the ad platform pixels fired on every link visit. Omitted fields keep their value and an empty string removes a pixel. Once any pixel is set, link visits go through a short browser page that fires the pixels and then redirects, which adds a short delay.

Requires the `integrations:write` scope.

API: PUT /v1/retargeting-pixels

```
linkbreakers retargeting-pixels update [flags]
```
