## linkbreakers analytics-data get-shared-locations

List shared locations

### Synopsis

Returns the precise positions visitors shared through a Location request workflow step, newest first, capped at 2000, with the total count. Without start_date and end_date it covers all time.

Requires the `analytics:read` scope.

API: GET /v1/analytics/shared-locations

```
linkbreakers analytics-data get-shared-locations [flags]
```
