## linkbreakers qrcode-design apply-template

Apply a QR code template to a link

### Synopsis

Copy all design settings from a community QR code template to an existing link's QR code design. This replaces the current design with the template's styling.

Requires the `qrcodes:write` scope.

API: POST /v1/qrcode-designs/apply-template

```
linkbreakers qrcode-design apply-template [flags]
```
