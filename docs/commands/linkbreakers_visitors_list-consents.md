## linkbreakers visitors list-consents

List a visitor's consents

### Synopsis

Returns the visitor's marketing consents, newest first, each with the wording shown, how it was given, the link, step and visit, and when. They are only ever added, so this is the proof of consent.

Requires the `visitors:read` scope.

API: GET /v1/visitors/{id}/consents
