## linkbreakers qrcode-templates resolve-qrcode-template-images

Resolve QR code template thumbnails

### Synopsis

Return freshly signed thumbnail URLs for the given templates. The URLs expire, so callers fetch them when they need to render rather than storing them.

Requires the `qrcodes:read` scope.

API: POST /v1/qrcode-templates/images:resolve
