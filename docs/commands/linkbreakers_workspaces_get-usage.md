## linkbreakers workspaces get-usage

Get the workspace's plan usage

### Synopsis

Returns every limit the workspace's plan sets (tracked visits, API calls, platform credits, team members, custom domains, webhooks, media storage) with what the workspace has used of it in the current cycle, when it resets and whether it has been reached. The numbers come from the counters that enforce the limits.

The plans themselves, with their prices and limits, are listed by [Pricing](https://linkbreakers.com/help/api/pricing).

Requires the `workspace:read` scope.

API: GET /v1/workspace/usage

```
linkbreakers workspaces get-usage [flags]
```
