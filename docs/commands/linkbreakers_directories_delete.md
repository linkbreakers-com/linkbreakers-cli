## linkbreakers directories delete

Delete a directory

### Synopsis

Remove a directory from the workspace. This operation cannot be undone. A directory cannot be deleted while it still contains links or child directories; move or remove them first.

Requires the `links:write` scope.

API: DELETE /v1/directories/{id}

```
linkbreakers directories delete [flags]
```

### Options

```

      --id string   The ID of the directory to delete. The directory must be empty before deletion; if it still contains links or child directories, the request fails. Required.
```
