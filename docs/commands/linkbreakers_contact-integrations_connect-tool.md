## linkbreakers contact-integrations connect-tool

Connect a contact tool

### Synopsis

Connect a contact tool with its credential, or replace the stored one. The credential is checked against the tool first. Identified visitors are then created or updated as contacts there, at every step of every link until the delivery setting narrows it.

Requires the `integrations:write` scope.

API: POST /v1/integrations/contacts/{tool}/connect

```
linkbreakers contact-integrations connect-tool [flags]
```

### Options

```
      --account string           What the credential belongs to, for the tools that need it next to the key: an account URL, a domain, a site id. Empty for the others (Bird).
      --api-key string           Its credential: the tool's API key or token. Bird: a workspace API key (bk_us1_... or bk_eu1_...) with the email_marketing write scope; the others: see contact_integration_connect.
      --data string              Request body as JSON. Use @file.json to read a file or - for stdin. Flags set fields on top of it.
  -h, --help                     help for connect-tool
      --idempotency-key string   Makes retrying this request safe. See components.parameters.IdempotencyKey.
      --tool string              The tool to connect. Required.
```
