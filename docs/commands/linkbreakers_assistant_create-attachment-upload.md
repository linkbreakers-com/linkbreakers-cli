## linkbreakers assistant create-attachment-upload

Start a direct attachment upload

### Synopsis

Reserve an attachment of up to 50 MB and get a presigned upload_url to PUT its bytes to, then call CompleteAttachmentUpload.

Requires the `assistant:write` scope.

API: POST /v1/assistant/uploads

