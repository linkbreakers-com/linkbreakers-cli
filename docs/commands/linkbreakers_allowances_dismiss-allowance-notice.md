## linkbreakers allowances dismiss-allowance-notice

Dismiss an allowance notice

### Synopsis

Hide the over-limit notice for one limit, for the calling member, until the limit's next cycle. Only a member can dismiss; an API token gets a permission error.

Requires the `workspace:write` scope.

API: POST /v1/allowances/dismiss

```
linkbreakers allowances dismiss-allowance-notice [flags]
```
